Parking Management System

Project Description

This is a Python-based Parking Management System. It manages vehicle entry, vehicle exit, parking slots and parking fees.

Features

- Vehicle Entry
- Vehicle Exit
- Parking Status
- Automatic Slot Allocation
- Parking Fee Calculation
- Save Parking Data

Technologies Used

- Python
- JSON
- File Handling

How to Run

1. Install Python.
2. Open the project in VS Code.
3. Run Parking_management.py.
4. Follow the instructions in the terminal.
